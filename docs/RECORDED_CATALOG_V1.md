# Canonical catalog recording v1

The extension in [`RECORDED_CATALOG_V2.md`](RECORDED_CATALOG_V2.md) adds date-level product segments, provider-supplied daily summaries, and daily support. V1 remains readable and its writer output remains byte-compatible for v1-shaped recordings.

WX.11 records a captured original canonical product as UTF-8 JSON. The writer is pure and has no disk, network, or clock access. WX.15 owns persistence. The one approved WX.11 fixture is `app/src/test/resources/catalog/wx11-full-sequence-v1.json`; it was generated from `SimulatedCatalogSource` with location ID `wx11-chicago-synthetic`, coordinates `41.8781,-87.6298`, zone `America/Chicago`, dataset ID `wx11-full-sequence-v1`, and `asOf` `2026-03-08T12:00:00.123456789Z`. Coordinates locate the synthetic reference only; the weather is invented. Its 88 facts span 44 local dates, including a DST transition. `issuedAt` is null because the synthetic product has no issue time. Support is copied from WX.10's declared fields and is complete for those fields; absent fields, including total precipitation, remain unsupported. It contains independent thunder probability, freezing rain, ice pellets, fog, zero rain/snow amounts, and null amounts. No provider truth or observation claim is made.

## Exact shape

The root object contains exactly `schemaVersion`, `location`, `datasetId`, `provenance`, `asOf`, `facts`, and `expectedSupport`. `schemaVersion` is integer `1`. `location` contains exactly `id`, `coordinates` (`latitudeDegrees`, `longitudeDegrees` as decimal-degree numbers), and `timeZone` (IANA ID). `provenance` contains exactly `origin`, `productKind`, `sourceId`, `productId`, and `issuedAt`. Original origin is `LIVE` or `SIMULATED`; `REPLAY` cannot be captured. IDs are descriptive. `asOf`, `issuedAt`, and all fact times are ISO-8601 instants with nanosecond precision. Optional strings and times use explicit JSON null.

Each `facts` object contains exactly `validTime`, `conditions`, `phenomena`, `temperatureC`, `precipitationProbabilityPercent`, `thunderstormProbabilityPercent`, `relativeHumidityPercent`, `cloudCoverPercent`, `windSpeedKph`, `windGustKph`, `windDirectionDegrees`, `rainAmountMillimeters`, `totalPrecipitationMillimeters`, `precipitationRate`, `snowfallCentimeters`, `snowDepthCentimeters`, `surfacePressureHpa`, `meanSeaLevelPressureHpa`, and `visibilityKm`. Conditions and phenomena are arrays of their canonical enum names. Nullable measurements are JSON numbers or explicit null. Accumulated amounts use `{ "value": number, "interval": { "start": instant, "end": instant } }`. Precipitation rate uses `{ "valueMillimetersPerHour": number, "meanInterval": interval-or-null }`. The canonical model defines all ranges and units; the wire format preserves Celsius, percent, km/h, degrees, millimeters, centimeters, hPa, kilometers, and mm/h without conversion.

`expectedSupport` is an array of `{ "date": local-date, "field": CatalogField name, "kind": "POINTS", "instants": [instant...] }` or `{ "date": local-date, "field": CatalogField name, "kind": "INTERVALS", "intervals": [interval...] }`. Every entry declares support, including values that are currently missing. Coverage is derived by `CatalogWindow`; it is not serialized. Empty facts or no support cannot produce a usable replay. Writer order is fixed: facts by valid time; support by date and field name; sets by enum name; support times/intervals by instant. Valid input ordering need not match writer ordering.

## Failure and replay mapping

Decode returns `MALFORMED` for JSON syntax, duplicate object keys, missing or noninteger version, and trailing content. Any integral version other than 1 returns `UNSUPPORTED_VERSION`; there is no older schema to migrate. Unknown fields, enum names, zones, invalid values, duplicate fact times/support entries, and invalid window support return `INVALID_VALUE`. The replay source requires exact location ID, coordinates, zone, dataset ID, and `asOf` match. Location and dataset mismatch return WX.9 `InvalidRequest` with their respective reasons. Other identity mismatches return `TransportFailure(INVALID_RESPONSE)` with `replay:identity_mismatch` detail. Other decode errors map to `TransportFailure(INVALID_RESPONSE)` with `replay:malformed`, `replay:unsupported_version`, or `replay:invalid_value` detail. Missing bytes return `NoData(EMPTY_SOURCE)`.

A successful or partial replay copies the canonical facts, location, dataset, `asOf`, product kind, source/product IDs, and `issuedAt`. It sets delivery `provenance.origin` to `REPLAY` and exposes the captured original origin separately in `CatalogLoadMetadata.replayOriginalOrigin`. Synthetic remains synthetic; an archived model remains an archived model. The replay source does not merge fields or read time. It returns `Partial` if any declared support is incomplete, otherwise `Success`.

Provider-derived fixture selection and round-trip evidence are deferred to WX.13 by owner decision on 2026-10-27.
