# OX-18 UI artwork board — minimal second world, same weather truth

**Approval status:** Product owner approved this artwork package for cycle `146-ox18-minimal-second-world` on 2026-11-16. Approval covers the visual target and constraints shown here; it does not authorize implementation. The vector and PNG are a schematic target, not installed evidence. Package fingerprints are recorded in the cycle plan.

**Artwork:** `.codex/concepts/OX-18-render-a-second-minimal-world-from-the-same-weather-truth-ui-board.svg` (editable vector source) and `.png` review render.

## Visual objective

Show the existing First City and a minimal, recognizably non-city composition using one catalog selection and the same selected-time semantic weather decisions. The candidate second world is a small open landscape with hills and two tree groups. It is deliberately sparse so the portability proof does not become a polished scene pack.

The side-by-side arrangement is a review sheet only. It does not propose split-screen presentation, scene switching, a world picker, new controls, or a change to the existing forecast foreground and timeline.

## State shown

- One illustrative supported-rain state is drawn in both scene canvases. The same cloud and precipitation decisions reach each world; rain marks are decorative and do not claim a measured amount or rate.
- The First City pane preserves the approved OX-05 cloud/depth/rain relationship and the OX-06 identity boundary. The landscape pane uses its own simple terrain composition without buildings.
- Both panes label the same exact selected instant `T`, catalog selection, evidence support, and source-time meaning. No forecast values, times, location, or fixture are invented by this board.
- The lower parity strip documents how supplied, eligible-carried, and unavailable evidence must remain equivalent in both worlds. An unavailable condition creates no condition-derived marks; an eligible carried condition keeps its original source time; independent supported facts remain.

## Preserved appearance and behavior

- Keep First City appearance, selected-time weather meaning, depth order, and semantic identities at their approved baseline.
- Keep the exact selected instant authoritative. Source-valid time remains distinct when evidence is carried.
- Preserve supplied values faithfully; do not infer cloud cover or correct weather through a plausibility rule.
- Keep cloud artwork within the approved upper third of the atmospheric scene. Rain artwork remains illustrative unless measured precipitation inputs exist.
- Keep forecast text and timeline readable and unchanged. The paired panes and all labels on this sheet are review annotations, not proposed app UI.

## Approved visual contract

The approved target uses the open-landscape candidate as a sufficiently distinct minimal non-city composition. It pairs that composition with the existing First City rain baseline using identical selected-time weather evidence and decisions, with only world-specific composition and artwork differing.
