# OX-112 UI Artwork Board

The SVG/PNG board compares the installed Urban Park screen with a scene composition built from the existing Park planes. The Drizzle example uses the selected rain icon, `Drizzle`, and Current Temp `49°`.

The oversized, weathered `49°` is the hero, with an illustrated rain icon enlarged alongside and overlapping its right edge. Large hand-painted `DRIZZLE` lettering sits beneath, matching the reference's order, scale, and expressive treatment. The whole reader is projectively mapped from a four-corner source region into the left brick wall, so its baseline, glyphs, icon, and spacing follow the wall's perspective. The projected artwork is clipped to the masonry face. Pigment edges are worn and slightly expanded, with the wall's brick detail visible through the paint. The mock has no guide marks, card, backing panel, drop shadow, or overlay-style keyline.

The reader sits below the lamp, left of the ivy, and above the bench. It occupies a separate Urban Park `MURAL_READER` layer after `FOREGROUND`; the tower location remains on its own `LOCATION_INSCRIPTION` layer in `MIDDLEGROUND`, with its code and placement untouched. Every timeline scrub updates the icon, description, and Current Temp from the selected instant. The current visual readout no longer repeats those three values. The apparent-temperature/Wind chill value and all other facts remain in their current presentation positions.

The artwork follows the Urban Living Park reference's format: oversized distressed temperature, a large illustrated weather symbol tucked against its right edge, and expressive hand-painted forecast lettering beneath. `OX-112-park-wall-reader-source.svg` is the unprojected vector source for the three dynamic elements; `OX-112-park-wall-reader-projected.png` is its four-corner projection used in the UI board. These static files illustrate the intended surface transformation. Runtime text remains dynamic and is to use the shared scene-core painted-text surface. The icon paths need the same shared projective transform, wall-face clipping, pigment expansion, and material treatment.

The Park-facing render function receives a compact value object from the existing typed, Meteo-backed presentation. It owns Park layout, target geometry, symbol selection, and pigment style; `:scene-core` owns generic glyph-path and painted-surface mechanics. This checkout contains `:app` and `:scene-core`, with Urban Park geometry and call-site code currently in `:app` and no separate `:urban-park` Gradle module.
