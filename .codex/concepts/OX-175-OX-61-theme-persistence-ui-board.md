# OX-61 theme persistence UI artwork supplement

This OX-61-only artwork supplement clarifies the visible cold-launch result.
The existing World control, forecast text, and timeline remain in their
current design. After the saved compatible installed theme resolves, that
world is visible and forecast access remains available. The forecast and
timeline shown after relaunch come from normal startup; this slice does not
promise that their exact previous values or scale survive process death.

The same-session switch continues to preserve the current place, catalog,
selected instant, forecast facts, and timeline state under OX-32. No new
banner, dialog, loading control, Settings surface, purchase UI, or unavailable
status treatment is introduced. OX-62 owns the unavailable-selection state.
